# Apex Pursuit: Redline Protocol

A browser-based 3D driving-game prototype set around a Seacrest County-inspired highway, with a garage-style interface and racing HUD.

## Play the game

**[Launch Apex Pursuit in your browser](./need_for_speed_hot_pursuit_seacrest_county_3d_multiplayer.html)**

> To play via a hosted website, enable GitHub Pages for this repository: **Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save**. After deployment completes, open:
>
> `https://sriramcj.github.io/Apex-Pursuit-Redline-Protocol/need_for_speed_hot_pursuit_seacrest_county_3d_multiplayer.html`

## Controls

| Action | Control |
|---|---|
| Accelerate | `W` / `↑` |
| Brake / reverse | `S` / `↓` |
| Steer | `A` / `D` or arrow keys |
| Nitro boost | `Shift` |
| Drift | `Space` |
| Camera | `C` |
| Enter / exit car | `F` or `Enter` |
| Return to garage | `Esc` |

## Notes

- The HTML file loads Three.js and other assets from external CDNs, so an internet connection is needed for those resources.
- This repository currently contains the standalone HTML prototype. Multiplayer-style interface elements in the prototype should not be assumed to mean a live multiplayer backend is configured.
- This is an independent fan-made prototype and is not affiliated with or endorsed by Electronic Arts or the Need for Speed franchise.
